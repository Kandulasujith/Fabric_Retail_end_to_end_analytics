# Retail Sales Analytics Project using Microsoft Fabric

## Project Overview

This project demonstrates an end-to-end analytics workflow built using Microsoft Fabric. The workflow includes data storage, ETL pipeline creation, data transformation, semantic modeling, and dashboard visualization.

## Architecture

CSV Dataset → Lakehouse → Data Pipeline → Warehouse → Semantic Model → Power BI Report

## Technologies Used

* Microsoft Fabric
* OneLake
* Lakehouse
* Warehouse
* Data Pipelines
* SQL
* Power BI
* Semantic Models
* Notebooks (Python)

## Project Workflow

* Loaded retail sales data into Lakehouse using OneLake storage.
* Built a data pipeline to move data from Lakehouse to Warehouse.
* Performed data transformation and analytical queries using SQL in Fabric Warehouse.
* Created dimension and fact tables for semantic modeling.
* Built relationships between tables using a star schema model.
* Developed interactive Power BI dashboards for business insights and reporting.
## Key Learnings

* Understanding Microsoft Fabric architecture
* Building ETL pipelines in Fabric
* Working with Lakehouse and Warehouse concepts
* Semantic modeling in Direct Lake mode
* End-to-end analytics workflow implementation in the cloud
